# 事件文档目录

此目录用于存放停电事件的详细文档（Markdown 格式）。

## 使用方法

1. 在此目录下创建与事件 slug 对应的 `.md` 文件
2. 文件名格式：`{slug}.md`（例如：`1965-northeast-blackout.md`）
3. 编辑 Markdown 文件，内容会自动显示在事件详情页

## 示例

已创建示例文件：
- `1965-northeast-blackout.md` - 1965年北美大停电
- `_template.md` - 通用模板（当找不到对应文件时使用）
