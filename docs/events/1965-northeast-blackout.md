# 1965年北美大停电

## 概述

1965年11月9日，美国东北部和加拿大安大略省发生了大规模停电事故，影响范围达20万平方公里，约3000万人受到影响，持续时间长达13小时。

## 事件经过

当天下午5点16分，位于安大略省的一个继电器保护装置发生误动作，导致一条输电线路跳闸。这一看似微小的故障引发了连锁反应，最终导致整个东北部电网崩溃。

## 影响

- **受影响人数**: 3000万人
- **影响范围**: 纽约州、新泽西州、宾夕法尼亚州、马萨诸塞州等
- **经济损失**: 数亿美元

## 启示

这次事故让人类第一次意识到现代电网的脆弱性，也推动了电网保护技术的发展。
